A merge gate for AI-agent-generated code: many parallel agent sessions go in, a small number of tested, risk-tiered, provenance-tagged commits come out.

  • Topics: ai-agents, audit, code-review, developer-tools, git, merge-queue, monorepo, provenance, python

What it does

Lanes (path-partitioned queues), batched merges with git merge-tree, targeted test suites cached by tree, bisection on failure, post-merge gate verify with automatic revert, risk tiers with a named approver, secret blocking, crash-safe compare-and-swap publishing, and gate audit, which rebuilds a provenance report from the target's own history. The recorded demo: 26 agent sessions, 19 merged, 6 rejected, 1 sent back, broken code never on main.

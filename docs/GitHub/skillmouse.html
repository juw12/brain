Use Claude Code, Codex, OpenCode and Gemini skills and agents with any model - from your mouse.

A lot of great open-source skills and agents are written only for Claude Code or Codex. SkillMouse finds them on your PC and runs them on whatever model you like - OpenAI, Anthropic, Gemini, OpenRouter, DeepSeek, Groq, or local models through Ollama / LM Studio.

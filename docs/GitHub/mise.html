Built Mise: a quiet kitchen game (home kitchen, or a small restaurant as chef, server or owner) with live-synthesised Web Audio ASMR, in plain HTML/JS

A cozy, ASMR-first cooking game: cook 8 recipes at home with no timer, or run a small restaurant as the chef, the server or the owner, in first or third person. Every sound is synthesised live with Web Audio. Sibling of Bilas.

  • Stack: plain HTML, CSS, JavaScript; Web Audio (no sample files); Playwright gates in tests/check.py, tests/nav_check.py, tests/audio_probe.py

From the README

Taiwan just made peak electricity expensive. Storage can now pay for itself.

Since Taipower's October 2025 tariff update, a high-voltage factory pays NT$9.39/kWh at the summer peak and only NT$2.53/kWh off-peak. That NT$6.86 spread, plus the MOEA subsidy of up to NT$5M per MWh, turns a behind-the-meter battery from "nice to have" into a 6-year payback.

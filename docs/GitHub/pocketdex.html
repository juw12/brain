From the README

A calm, pixel-sprite Pokédex that you also use every day, with a small 3D meadow where the Pokémon you catch come to rest. All 1025 Pokémon, sprites and fonts are bundled; no account, progress stays in the browser. Styled after Jeda (warm paper, soft cards, serif titles, floating pill tab bar) and the Sansa idea of "a quiet place you visit, not a game you win".

What it is

A search page for questions where the source matters. The browser asks up to 23 public libraries directly (10 on every search, 13 more when the query calls for them); there is no Telisik server, account, tracker or API key. Results are pooled and ranked with a formula printed on the page, and each result can open the arithmetic behind its position.

  • In the sources' own words: up to three sentences copied character for character from the top results.
  • Before AI: one switch limits results to items dated up to 30 November 2022 (a date filter, not a detector).
  • Lenses: All, Learn, Research, Build, Discuss re-weight the sources.
  • Cite, search operators, bangs.
  • In the browser: an install button where the browser offers one, address-bar search (OpenSearch), a place in the Android share sheet once installed. Tested in Chrome 157 and Firefox 150.0.2.
  • Optional Stack Exchange key field in Settings (the key stays in the browser).
  • Browser extension (optional, in extension/, Chrome, Edge and Firefox): Telisik as the new tab page, the address-bar keyword tk, right-click "Search Telisik" on selected text, and a toolbar button (Alt+Shift+K). One permission (contextMenus), no site access. Loaded by hand from the repo; not in the Chrome Web Store or addons.mozilla.org.

The niche: web results crowded with pages written to rank and sell (Bevendorff et al., ECIR 2024) and answer engines whose citations often do not check out (Liu, Zhang, Liang 2023; Tow Center / CJR, March 2025). Telisik only asks places with no shop window and prints only what a source wrote.

Honest limits

  • Not the best search engine overall. It is the best I could find for one narrow job: free, no account, ads or tracking, one query across 23 public libraries, verbatim quotes only, ranking arithmetic on show.
  • The one measured lead over other search engines' own add-ons is permissions (see Quality). It is not a lead in search quality, and the extension is in no store.
  • It is a page plus an extension, not a browser. Chromium and Firefox are what it runs in, so it cannot beat them; it installs from them and plugs into their new tab page, address bar, right-click menu, toolbar and share sheet. On a real new tab the cursor starts in the address bar in Chrome, Edge and Firefox (measured). Each browser asks once whether to keep the new tab page.
  • The test favours Telisik by construction: every right answer is a page inside a library it searches (mostly Wikipedia). The sets were written by an AI assistant and 50 unseen queries is a small sample.
  • Google, Bing, ChatGPT and Perplexity were not measured: their terms forbid automated queries. Marginalia (502), Stract (404) and DuckDuckGo's instant-answer interface (timeout) did not answer on 2026-11-16 from the network this ran on.
  • Ranking is lexical. Questions that share no words with the page still miss: "how do airplanes stay in the air", "tallest mountain on earth", "largest planet in the solar system", "general rise in prices over time", "the smallest unit of life", "building blocks of proteins". New in set 3: "the planet closest to the sun" has Mercury at 32 and "deepest part of the ocean" has the Mariana Trench at 12. Fixing these needs a meaning model, which is not shipped.
  • No news wire: GDELT answered 429 on 2026-11-16 and was not added. Government sources are UK and US only.
  • Free API quotas are per visitor IP (Stack Exchange about 300 a day, GitHub about 10 a minute). The key field in Settings raises the Stack Exchange quota (about 10,000 a day per Stack Exchange's documentation); each user has to register a key himself, none is shipped.
  • The extension is not in the Chrome Web Store or addons.mozilla.org: both need a developer account in Juwen's own name (Chrome's has a one-time registration fee, Firefox needs Mozilla signing). The zips are built by tools/pack_extension.py into dist/. In Firefox it loads as a temporary add-on that disappears when Firefox closes. The GitHub token field was left out on purpose.
  • Income today is 0. Two hooks exist in js/config.js (support link, one labelled footer sponsor line); both are empty and need a payment account in Juwen's own name.
  • The name got a web check only, not trademark clearance: nine small GitHub repos, a dance programme and an old TV programme use the word.

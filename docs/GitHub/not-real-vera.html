What it is

An AI avatar channel for YouTube Shorts, Instagram Reels and TikTok, presented by Vera. Since the second request (below) the videos no longer say she is an AI. Each 35-45 second episode shows one scam, how an AI would write it, and one 10-second check that stops it, with the source alert on screen and in the caption.

  • Niche pick: scam and deepfake defence (first scored with an openly-AI host). Scored 4.60 on the matrix in niche.md against 3.50 for finance and 3.40 for tech tutorials. The scores are judgements, and the 30-day test in niche.md decides if it works.
  • Five launch episodes, each traced to an FBI IC3 alert saved in docs/sources/: toll text, cloned family voice, wrong-number crypto, fake deputy call, account-takeover alert.
  • pipeline/make_episode.py renders 1080x1920 video with voice, captions and sound cues.
  • pipeline/autopost.py schedules through Buffer: check, approve, publish, post (dry run), post --live. An episode is never posted without an approval file.
  • tools/gates.py: ten pass/fail checks on scripts and renders.

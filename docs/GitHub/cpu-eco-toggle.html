What it is

A Windows tray icon (green = ON, grey = OFF). ON moves windowless background processes (opencode, cargo, rustc, ollama, llama-server, python, pythonw and headless msedge; never anything Vector started, never a process with a visible window) onto cores 3-7 (mask 0xF8, 5 of 8) at BelowNormal priority and re-applies that every 30 s so new jobs are caught. OFF puts every changed process back to its original priority and cores, including child processes that inherited the limit. A second launch toggles the running copy, so a pinned taskbar shortcut works as an on/off button. Right-click: status, trim background memory, exit.

Measured

  • On this PC (8 cores): OFF -> 0 processes limited, ON -> 35 processes limited. Nothing was stopped.
  • Why it was built: the PC was at 100% CPU and 97% RAM from background jobs. The limit leaves about 3/8 of the CPU for interactive work; total CPU stayed high (about 92% average) because Vector and the apps in use were the rest.

Limits

  • Windows only (Windows PowerShell 5.1 and WinForms).
  • Only the process names listed above; affinity and priority last until a process restarts.
  • The tray icon can hide behind the tray arrow; drag it onto the taskbar. Pinning the Start-menu shortcut is manual.
